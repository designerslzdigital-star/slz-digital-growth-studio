# SLZ Digital Software

Institutional website for SLZ Digital Software: custom software, systems, SaaS and apps.
Static, multilingual site — the only conversion point is a WhatsApp link.

## Languages

Four versions, each with its own URL: `/pt-br`, `/pt-pt`, `/es`, `/en`.
All copy lives in `src/i18n/locales/` (one file per language, typed by the pt-BR dictionary).

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

- TanStack Start
- TypeScript
